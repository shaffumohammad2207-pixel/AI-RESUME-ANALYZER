# AI Resume Analyzer 🚀

A simple and modern AI Resume Analyzer web application built using HTML, CSS, and JavaScript.

## 🌟 Features

- 📝 Create and manage resume details
- 🎨 Modern and responsive user interface
- 📄 Resume templates
- 👤 Student and professional resume support
- ⚡ Interactive JavaScript functionality
- 📱 Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
